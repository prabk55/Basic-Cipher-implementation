# Basic-Cipher-implementation
implemented AES-128 and vigenere cipher from scratch
<br>
no external cryptography libraries is used
<br>
This program assume the input to be in uppercase 
<br>

## Features
-ECB mode<br>
-PKCS#7 paddling<br>
-hexadecimal encoding<br>
-encryption<br>
-decryption

## how to use
mode : for vigenere use "-vig" and for AES use "-aes"<br>
E/D : for encryption use "-e" and for decryption use "-d"<br><br>

syntax : -E/D -mode key plaintesxt/ciphertext
